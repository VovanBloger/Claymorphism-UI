# Анимации и состояния ClayCraft UI

Источник: `reference-clay.css`, `ReferenceElements.tsx`, общие компоненты Motion; 2026-11-14.

## Принцип

Движение объясняет действие пользователя и массу объекта. Предмет сначала немного сжимается вниз, затем спокойно возвращается. Поверхность и текст остаются читаемыми. Состояние не должно зависеть от того, успела ли закончиться анимация.

Общая кривая новых CSS-взаимодействий: `cubic-bezier(.22,1,.36,1)`. Движение не меняет размеры CSS-layout: используются transform и стабильная геометрия. Имеющиеся Motion-компоненты наследуют `MotionConfig reducedMotion="user"`.

## Конечный автомат

Кнопка: idle → hover → press → hover/idle. Выбранный toggle/chip использует независимое persistent state, которое не сбрасывается после pointer-up. Обычный hover не должен менять бизнес-состояние. Нажатие через Enter/Space вызывает тот же onClick, что и мышь.

Кольца: initial (78/52/90) → goal-complete (100/52/90) → reset. Графический прогресс и доступное имя SVG меняются из одного state, чтобы не показывать противоречивые значения.

Календарь: displayed month и selected ISO day независимы. После перехода в другой месяц выбранная старая дата сохраняется в подписи. День подсвечивается только при совпадении полного ключа год-месяц-день. Число дней и смещение первой даты вычисляются из Date.

## Уменьшение движения

В CSS есть `@media(prefers-reduced-motion:reduce)`: animations и transitions отключены, hover/press новых элементов не деформируют объект. В App есть MotionConfig. Конечные состояния, подписи, галочки, выбранные дни и значения прогресса сохраняются.

Не включать reduced motion только через CSS для Motion-компонентов: JS-transform тоже должен уважать системную настройку. Не отключать саму функциональность вместе с анимацией.

## Доступность и производительность

У переключателей role=switch / aria-checked; у toggle-кнопок aria-pressed; у навигации стенда aria-current. У новых действий есть доступные имена, нативные кнопки и range; результаты объявляются через role=status. Focus-visible имеет контрастный фиолетовый outline с отступом.

Для animation budget использовать transform/opacity; не анимировать высоту всей страницы. Небольшое изменение box-shadow допустимо у отдельных controls. Не добавлять бесконечную анимацию всем карточкам. Старые декоративные clay-float сохранены, но отключаются при reduced-motion.

## Экспорт

Новые React-компоненты используют тот же модуль, что live-превью, а CSS экспортируется из того же файла. Это снижает расхождение поведения между стендом и скопированным кодом. Общие JSON-токены описывают общую механику внешней поверхности; точные частные длительности перечислены здесь и в CSS. Для embedded use не забывать подключить экспортированный CSS.

## Прокрутка и объёмные кольца · уточнение 2026-11-14

Кольца сохранили плавное изменение stroke-dasharray за 700ms: оба слоя используют pathLength=100 и одинаковый процент, поэтому торец не отстаёт от поверхности. При prefers-reduced-motion переход отключён существующим общим правилом. Число и подпись SVG остаются на фиксированных координатах и не подпрыгивают при 742/950.

Clay Scrollbar использует нативное перемещение бегунка без отдельной JS-пружины; hover/active меняют материал. Focus-visible остаётся вокруг прокручиваемого region. Клавиатурная прокрутка проверена PageDown/ArrowDown.
