# Магическая шкала прогресса

## Где находится

Библиотека → после примеров нижнего меню → «Маленькие шаги. Большая магия.». Компонент `src/components/MagicProgress.tsx`, оформление `magic-progress.css`, чистая логика `src/utils/magicProgress.ts`.

## Персонажи и материал

Пять уровней: Искорка (улыбка), Очарование (подмигивание), Сияние (маленькая звезда на теле), Орбита (кольцо Сатурна), Величие (корона/мантия). Исходный референс пользователя «Магическая шкала прогресса и звёзды.png» не менялся. Через imagegen подготовлен прозрачный RGBA-атлас2172×724, `public/assets/magic-progress/stars.png`, около766KiB. Это адаптация персонажей из референса; не побитовая нарезка оригинала. SVG viewBox показывает отдельные области без изменения пропорций; пути работают под GitHub Pages.

Каждый следующий персонаж крупнее; размер ограничен clamp/cqw, на узком экране минимум28–40px, desktop максимум76–132px. Пустые слоты имеют форму мягкой звезды, сиреневый градиент и внутреннюю SVG-тень. Фон трека светлый лавандовый, верхний мягкий блик и короткая контактная тень. Космический слой — тёмный сине-фиолетовый градиент, бирюзовые/розовые SVG-туманности и34 звёздные частицы. Светящийся фронт совпадает с долей заполнения.

## Управление и движение

- От2 до5 этапов; при сокращении выбираются уровни по всему диапазону, первая и финальная звёзды сохраняются. Пять этапов используют всех персонажей.
- Скорость0,5–2×, шаг0,25. Длительность пути на1× — count×2000ms. Скорость влияет на заполнение, приветствие персонажа, всплеск искр и движение космоса.
- Центры чекпоинтов на10–90% длины трека. Звезда загорается, когда progress достигает её центра. Ни индекс таймера, ни заранее установленный CSS delay не управляют зажиганием.
- Однократное мягкое появление: scale(.35,.25), сжатие/растяжение, небольшой подъём и поворот, спокойная посадка. Базовая длительность680–1080ms по уровню, делится на скорость. Искр5/7/9/11/13; радиус всплеска45–81px. После активации остаётся статичный мягкий ореол; последняя звезда получает более широкий золотой свет.
- Пауза/продолжение, сброс, повтор. Смена количества этапов сбрасывает путь; смена скорости продолжает текущий. RAF отменяется при размонтировании, время скрытой вкладки не засчитывается, delta ограничен64ms для долгих зависаний.
- При prefers-reduced-motion запуск сразу завершает путь, а CSS-движения отключены. Это предусмотрено кодом; системный режим в реальном браузере отдельно не переключался.
- role=progressbar, aria-valuenow/valuetext, live status только при новых достижениях, нативный клавиатурный range, кнопки количества с aria-pressed.
