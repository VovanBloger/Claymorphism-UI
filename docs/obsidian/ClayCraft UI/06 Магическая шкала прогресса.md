# Магическая шкала прогресса

## Где находится

Библиотека → после примеров нижнего меню → «Маленькие шаги. Большая магия.». Компонент `src/components/MagicProgress.tsx`, оформление `magic-progress.css`, чистая логика `src/utils/magicProgress.ts`.

## Персонажи и материал

Пять уровней: Искорка (улыбка), Очарование (подмигивание), Сияние (маленькая звезда на теле), Орбита (кольцо Сатурна), Величие (корона/мантия). Исходный референс пользователя «Магическая шкала прогресса и звёзды.png» не менялся. Через imagegen подготовлен прозрачный RGBA-атлас2172×724, `public/assets/magic-progress/stars.png`, около766KiB. Это адаптация персонажей из референса; не побитовая нарезка оригинала. SVG viewBox показывает отдельные области без изменения пропорций; пути работают под GitHub Pages.

Каждый следующий персонаж крупнее; размер ограничен clamp/cqw, на узком экране минимум28–40px, desktop максимум76–132px. Пустые слоты имеют форму мягкой звезды, сиреневый градиент и внутреннюю SVG-тень. Фон трека светлый лавандовый, верхний мягкий блик и короткая контактная тень. Космический слой — тёмный сине-фиолетовый градиент, бирюзовые/розовые SVG-туманности и34 звёздные частицы. Светящийся фронт совпадает с долей заполнения.

## Управление и движение

- От2 до5 этапов; при сокращении выбираются уровни по всему диапазону, первая и финальная звёзды сохраняются. Пять этапов используют всех персонажей.
- Скорость0,5–2×, шаг0,25. Длительность пути на1× — count×2000ms. Скорость влияет на заполнение, приветствие персонажа, всплеск искр и движение космоса.
- Центры чекпоинтов на10–90% длины трека. Звезда загорается, когда progress достигает её центра. Ни индекс таймера, ни заранее установленный CSS delay не управляют зажиганием.
- Однократное мягкое появление: scale(.35,.25), сжатие/растяжение, небольшой подъём и поворот, спокойная посадка. Базовая длительность680–1080ms по уровню, делится на скорость. Искр5/7/9/11/13; радиус всплеска45–81px. После активации остаётся статичный мягкий ореол; последняя звезда получает более широкий золотой свет.
- Пауза/продолжение, сброс, повтор. Смена количества этапов сбрасывает путь; смена скорости продолжает текущий. RAF отменяется при размонтировании, время скрытой вкладки не засчитывается, delta ограничен64ms для долгих зависаний.
- При prefers-reduced-motion запуск сразу завершает полный путь или выбранный этап, а CSS-движения отключены. Это предусмотрено кодом; системный режим в реальном браузере отдельно не переключался.
- role=progressbar, aria-valuenow/valuetext, live status только при новых достижениях, нативный клавиатурный range, кнопки количества с aria-pressed.

## Настройка толщины · 16.11.2026

Ползунок «Толщина» меняет физическую высоту трека от24 до112px с шагом2px, исходное значение72px. Значение одинаково на desktop и mobile: прежний фиксированный mobile override58px удалён. Толщина хранится отдельно от времени/количества этапов, поэтому изменение и сброс прогресса не сбрасывают выбранную высоту. При выходе из библиотеки локальная настройка сбрасывается вместе с компонентом.

CSS-переменная --track-height управляет оболочкой; космос, туманности и светящийся фронт заполняют её по inset/100%. Трек центрируется translateY(-50%) относительно той же оси --track-center, что и звёзды. Размеры и активация персонажей не меняются. Отступ подписей выбирается по наибольшему из исходного отступа, половины толщины+14px и радиуса крупной звезды+10px; высота области при необходимости увеличивается. Общий класс magic-range оформляет оба нативных slider. Есть числовой output, aria-label/valuetext и клавиатура Home/End/стрелки.

Проверки: в браузере фактическая высота24/112px, совпадающие центры трека/звёзд, неизменная ширина первой звезды62,984px и прогресс50% при обоих значениях. На390px при112px зазор до подписей14px, document376px без overflow. Консоль без ошибок; lint, build и diff-check прошли. Прежнее предупреждение JS>500kB сохраняется. Скриншоты output/qa/magic-thickness.jpg (48px), magic-thickness-mobile.jpg (112px). Источник4b0c924.

## Быстрый просмотр этапов · 16.11.2026

Каждая звезда и её подпись — одна нативная кнопка с aria-label и aria-pressed. Клик, Enter или Space возвращает заполнение к предыдущему чекпоинту и проигрывает выбранный отрезок за 900 ms при 1×; регулятор скорости сохраняется. Повторный клик снова показывает появление звезды. Во время движения можно выбрать другой этап. Предыдущие звёзды показываются уже зажжёнными без повторного приветствия.

Обычное превью останавливается точно на выбранном чекпоинте. **Последний этап проходит за центр финальной звезды до 100% трека**, чтобы справа не оставался пустой хвост. Финальная звезда всё равно загорается на своём пороге 90%, пока космос движется дальше. «Продолжить» после промежуточного превью заполняет оставшийся путь с обычной скоростью, «Ещё раз» после финального — запускает весь путь заново. Пауза посреди превью сохраняет его цель; сброс и смена числа этапов очищают её.

Форма, размеры и характер активации сохранены. На наведении звезда слегка увеличивается, при нажатии сжимается; прямоугольной подложки и press-тени нет. Клавиатурный фокус обозначен круглым контуром. У мелких звёзд увеличена невидимая зона нажатия. targetProgress в чистой функции advanceMagicProgress ограничивает время выбранным порогом; миллисекунды не округляются, чтобы дробные пороги четырёх этапов не застревали перед звездой.

Проверено в браузере: выбор и повтор второго этапа до30%, пауза53% → продолжение до70% → весь путь100%, Enter на первом этапе10%, клик по подписи при4 этапах, переключение цели на лету. Финальный этап при2 и5 звёздах завершает100%. На390px документ376px без горизонтального overflow; ошибок консоли нет. Скриншоты: output/qa/magic-stage-preview.jpg и magic-stage-preview-mobile.jpg. Системный reduced-motion отдельно не эмулировался. lint,17/17 тестов и build прошли; прежнее предупреждение о JS >500kB остаётся. Источник:7cd300a.
