## Что делает приложение

Четыре раздела: библиотека интерактивных образцов, генератор UI, макеты и дизайн-система. Главный экран — дашборд. Библиотека, экран входа и пак ассетов открываются внутри его правой области с постоянной боковой навигацией. Генератор экспортирует React/TSX, CSS и JSON-токены, позволяет менять материал внешней поверхности, тени, скругления, ассеты и текст.

Старые макеты: музыкальный дашборд, экран входа, пак PNG-иконок и маскотов. Новая библиотека собирает формы из четырёх пользовательских референсов: UI-kit, магазин, музыкальный дашборд и фитнес-приложение. Это адаптация визуального языка, а не заявление о пиксельном совпадении всех экранов.

Новые экспортируемые элементы: `status-pills`, `action-rows`, `clay-calendar`, `product-card`, `workout-card`, `activity-rings`, `filter-chips`. Кроме них, на главном стенде есть коралловая кнопка, переключатель, вертикальный range, кнопка-сердце, колокольчик, настройки и сегментированная навигация. Кнопка-капсула `pill-button`, ранее существовавшая в движке, теперь доступна в списке архетипов генератора.

## Технологии и фактический статус

React 19, TypeScript, Vite 8, Tailwind 4, Motion, lucide-react. Входные файлы `index.html` → `src/main.tsx` → `src/App.tsx`. В исходниках нет вызовов Gemini, серверного API, авторизации, хранения корзины или тренировки. Зависимости AI Studio присутствуют в исходном package.json, но API-ключ для текущего UI не нужен.

Состояние демонстраций хранится в React и сбрасывается при размонтировании раздела/перезагрузке. Товар, избранное и запуск тренировки — интерактивные UI-демонстрации, не реальные покупки/тренировочная платформа. Кнопка Download в образце списка показывает подсказку об экспорте в генераторе; файл сама не скачивает.

Репозиторий Git инициализирован на ветке `main`; установлен remote `origin` → `https://github.com/VovanBloger/Claymorphism-UI.git` (открытый репозиторий `VovanBloger/Claymorphism-UI`).

## Локальный запуск

```powershell
npm install
npm run dev
npm run lint
npm test
npm run build
```

Стандартный dev-скрипт использует `0.0.0.0:3000`. Для проверки только с этого компьютера:

```powershell
npm exec -- vite --host 127.0.0.1 --port 3001
```

В текущей сессии визуальная проверка выполнена на `http://127.0.0.1:3001/`. Это локальный предпросмотр, не адрес опубликованного сайта. Внешние Google Fonts могут требовать сеть; есть sans-serif fallback.

Шапка содержит только бренд и подпись. Настройки генератора сохраняются при смене раздела в пределах сессии.

## Компактная навигация и новые компоненты · 2026-11-14

В sidebar остаются только Dashboard и 5 реальных разделов проекта. Демонстрационные My Music, Favorites, Playlists, Podcasts, Activity, Settings, а также нереализованный premium-блок убраны из sidebar. Это не удаляет KPI Favorites и другие образцы внутри самого музыкального макета. В дизайн-систему добавлен интерактивный раздел Clay Scrollbar. Кольца активности в библиотеке и экспорте получили объёмный рендеринг без контура (`erode` + `innerMask` + мягкий блик и треки) и точно отцентрированное число; правила анти-контура зафиксированы в [[ClayCraft UI/02 Стиль и правила компонентов|правилах стиля]] и в разделе 2 `DesignSystemGuide`.

## Sticker Notch — дополнительный вариант нижнего меню

В генераторе доступен архетип `sticker-notch-nav`, в дизайн-системе — интерактивный стенд «Sticker Notch · пластилиновая выемка». Он переносит поведение нижнего меню из проекта Генератора стикеров: приподнятый белый медальон, синхронная выемка, перелёт, деформация и смена иконки. Прежний ClayBottomNav остаётся отдельным вариантом.
