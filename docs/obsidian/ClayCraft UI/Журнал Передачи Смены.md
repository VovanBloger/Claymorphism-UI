Столбики dashboard без желобов, donut — матовые клинья. [[ClayCraft UI/07 Общий свет и материал|Правила]] · [[ClayCraft UI/08 Исследование пластилинового объёма|Исследование]].

Браузер: библиотека/графики/меню,390px без overflow, Confirm, клавиатурные действия и свет; local depth/specular меняют bitmap. Настоящий автономный export mount/unmount:2→0→2 runtime-style, соседняя непомеченная кнопка не меняется, errors[]. После чистой загрузки приложения0 ошибок. Для SVG нужны собственные контуры, прямоугольная карта туда не переносится. Редкий HMR сброс контекста во время правок исчез после чистой загрузки.

- **Деплой:**1817432 отправлен в gh-pages. Публичный https://vovanbloger.github.io/Claymorphism-UI/ уже отдаёт index-D87nIlAV.js и index-P_KJh_Ak.css.
