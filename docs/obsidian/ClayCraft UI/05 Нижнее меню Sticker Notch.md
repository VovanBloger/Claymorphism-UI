# Нижнее меню Sticker Notch

## Назначение

Дополнительный нижний dock для ClayCraft UI по запросу пользователя: поведение меню с приподнятой кнопкой из [[Генератор Стикеров ТГ/00 Обзор проекта Генератор Стикеров ТГ|Генератора стикеров]]. Прежний Clay Dock сохранён. Найти: Генератор UI → «Нижнее меню · Sticker Notch» или Библиотека → «Интерактивный стенд нижнего 3D-меню» → «Sticker Notch · пластилиновая выемка».

## Происхождение

На 2026-11-14 прочитаны `D:\Projects\Генератор стикеров\components\AdaptiveNotchNav.tsx` и `lib/notch-math.ts`. Чистая математика перенесена без изменения формул в `src/utils/notchMath.ts`; 6 её тестов также перенесены. UI адаптирован под React/Vite и только clay-lavender: без Next.js, Telegram-профиля, звука и haptics. Исходный проект не редактировался.

## Материал и геометрия

- SVG-панель высотой 90px, верхняя грань на y=22; нижние углы 28px.
- Белый медальон 50×50px, покоится центром на y=22. Материал #FFFEFE → #FAF6F9 → #ECE1F8; иконка #6D49C8.
- Панель #C7ACF0 → #AA86DF, мягкие inset-фаски через альфа-маски, нижний торец со смещением 3.5px, рассеянные фиолетовые drop-shadow. Контрастной контурной линии нет.
- SVG-выемка строится симметричными дугами из исходной функции buildSymmetricalNotch; её центр следует центру шара. Для узкого preview адаптер уменьшает gap, чтобы крайняя выемка не уезжала от кнопки.
- Пункты: Создать / Мои паки (бейдж 3) / Чат / Лента. В активном пункте иконка находится в медальоне, подпись появляется внизу. При выборе «Мои паки» бейдж переходит на медальон.

## Поведение

Один requestAnimationFrame-цикл обновляет SVG-path, нижний торец и положение/деформацию шара. Вылет мягкий, подъём не более 4.5px, растяжение зависит от расстояния. Иконка затухает, меняется в середине и появляется к посадке. Повторный выбор во время движения начинает новый перелёт с текущей позиции. После завершения точная конечная X-координата и scale(1,1).

ResizeObserver измеряет реальную ширину. При изменении размера медальон/выемка сразу встают под выбранный пункт. При размонтировании RAF и observer освобождаются. При prefers-reduced-motion движение мгновенное; остальные состояния и выбранный пункт сохраняются.

Навигация доступна кнопками, Left/Right, Home/End; один активный tabIndex=0, у выбранного пункта aria-current=page. Focus-ring не скрывается. Локальный status-текст подтверждает открытый раздел. Это демонстрационная навигация, а не маршрутизация самого ClayCraft.

## API

```tsx
import { StickerNotchNav, StickerTabId } from './StickerNotchNav';
const [active, setActive] = useState<StickerTabId>('create');
<StickerNotchNav activeId={active} onSelect={setActive} speed={0.6} />
```

StickerNotchNavDemo хранит выбранный пункт самостоятельно и используется в генераторе и блоке BottomNavExamples библиотеки. Публичный компонент может быть контролируемым родителем.

## Экспорт

Архетип `sticker-notch-nav`: TSX-модуль включает геометрию и физику; внешний локальный import notchMath удаляется. Нужны react, motion и lucide-react. CSS из соседней вкладки сохраняется как `sticker-notch-nav.css`. JSON содержит тему, геометрию, интервалы движения и клавиатурный контракт.

Материал фиксирован по clay-lavender, как на референсе. Универсальные параметры фасок/ассеты других архетипов не перекрашивают этот вариант. Для других тем расширять параметры осознанно, а не менять исходные формулы.
